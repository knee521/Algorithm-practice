# Stock 学习心得

本目录用于记录股票类动态规划问题的实现代码、解题思路、易错点和复盘结论。

- [ ] 买卖股票的最佳时机

- [ ] 含手续费的股票买卖

## 核心思路

- 用持有股票和不持有股票表示每天的状态，分别记录两种状态下的最大收益。
- 根据题目限制增加冷冻期、交易次数或手续费等状态，并明确每天的状态转移顺序。
- 先写出状态定义和转移方程，再根据依赖关系压缩数组空间。

## 易错点与边界条件

> 记录交易次数、是否持股、冷冻期、手续费、买入卖出顺序，以及空数组和单日价格等边界情况。

## 复盘
