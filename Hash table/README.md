## 核心思路

- `set`：只关心元素是否出现，适合去重和快速判断存在性。
- `dict`：保存“键—值”映射，适合统计频次、记录下标或保存计算结果。
- 先确定查询条件，再选择键和值；键必须可哈希，字典中的键不重复。
